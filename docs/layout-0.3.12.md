# 0.3.12 布局蓝图

用户选择素材优先。复用现有本地 Electron／原生模块界面，不新增框架或远程依赖。

用户后续提供红框示意并明确确认「左侧导航也移到顶部」。现代布局改为横向顶部导航，全部／普通／特效／音频／收藏／点赞／未分类横向展示；顶部「分类」展开保留原层级、搜索、新建、置顶与管理能力的分类面板，「更多」展开皮肤、连接和更新。顶部保留路径、AN 状态、详情和外观设置；标题与三个导入入口一行，搜索、密度、筛选、排序在下方一行。素材区不再占用永久侧栏宽度。正文给预览更高比例与更宽的自动卡片；批量操作按选择出现。空态、预览失败、生成状态、音频入口保持原有流程。

经典布局保留原左侧导航，通过根属性撤除现代覆盖，面板容器在经典版恢复原有伸缩和分类滚动。独立顶部导航控制器只切换面板、焦点和ARIA状态，分类选择／外部点击／Escape收起，卸载释放监听；切布局不移动或重建导航及卡片。详情仍按需打开。外观设置与文件导入对话框分别管理。

新主题：雾白（浅灰与蓝色）、石墨（中性深灰）、青灰（浅灰绿）；保留紫夜与暖米。语义颜色覆盖文字、表面、边线、选中、成功与错误，不用大面积装饰渐变或额外动态背景。新主题文字对背景做自动对比检查，实际菜单与对话框逐个视觉检查。

响应规则：1480×940 标准窗、1080×760、930×700 小窗、850×600 最小窗；窄窗搜索可以单独成行，导入入口不截断；详情在既有窄屏规则下展示。布局切换只改变 CSS 和列数，不触碰素材、筛选、页码、选择、焦点和音频。

验收：偏好白名单与重启、存储故障；五色在两布局可自由组合；搜索、类别与详情开关无横向溢出，按钮可键盘访问；同一筛选／选择／页码在布局切换后保留；原件字节与索引不因外观变化而修改；反复开关外观窗不累积监听或轮询。安装包与远端发布待用户测试。
