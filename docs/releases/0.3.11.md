## 怎样更新预览

1. 点击素材预览图打开大图，或选中素材并打开右侧详情。
2. 点击「更换预览图」，选择本机 PNG、JPG、JPEG、WebP 或 GIF。也可点击「重新生成预览」，由管理器离线生成。
3. 新图立即更新到卡片、详情和大图中，分类、搜索、标签和收藏继续保留。
4. 需要恢复时，在 48 小时内点击「撤回预览更换」。多次更换可逐次撤回，重启后仍然可用。

音频没有图片预览操作。取消选择或选到无效图片时保留原预览；重新生成失败时保留已有图片，并显示失败原因。

## 48 小时后怎样清理

旧图和 GIF 封面从被替换时起保留 48 小时。当前使用的预览、其他素材仍在用的图片及撤销移除所需的图片继续保留。到期后清理不再引用的旧缓存；软件已经关闭时，在下次启动清理，退出后不会留下后台清理进程。

撤回只恢复图片，不回退后续分类、名称、标签等操作。外部原始 FLA 和所选图片不会被修改或删除。
