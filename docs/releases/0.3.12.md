# 0.3.12 本地测试说明

新增用户选择的「素材优先」布局：左侧导航移到顶部横向展示，「分类」展开原有层级和搜索，「更多」提供皮肤、连接和更新。素材区获得整行宽度，自动密度使用更宽的卡片与更大的预览。导入普通素材、特效和音频仍可直接操作，AN 打开与舞台粘贴保留明确按钮。

点击右上角「外观」切换新版／经典版，可独立选择紫夜、暖米、雾白、石墨、青灰。更改即时生效并保存在本机；切换保留当前分类、搜索、选择、分页和音频试听。原有底图皮肤可继续通过顶部「更多」中的「更换皮肤」或外观窗口内「更换底图」设置；经典版保留左侧入口。

网格仍支持自动／每行 4、5、6 个，窄窗自动减少列数。经典布局保留原有页面尺寸；详情仍按需展开。外观变更不修改素材、原始文件或分类记录，不新增后台轮询或依赖。

管理器为 0.3.12，随附 AN 插件仍为已验证的 0.3.11，本次无需更新插件。请正常退出当前管理器后从桌面图标重新打开，在新版和经典版中测试常用操作。原 0.3.11 程序及快捷方式备份保留供回退。

本轮仅交付完整运行目录与桌面入口，不生成安装包／便携包，也不提交、推送或公开发布；用户测试完成后再安排安装包。
