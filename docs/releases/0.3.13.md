# 0.3.13 本地测试版

2026-11-15。安装包和公开发布等待用户测试。

- 顶部六个大类：特效、音频、人物、场景、道具、表情；项目文件夹可以汇集一部剧的不同素材。
- 搜索、大类和大类的下一层标签在滚动时保持可用。人物提供现代都市、玄幻修仙、近代人物、古代人物；原有同名分类沿用，旧分类和素材归属保留。
- 每行增加7个、8个，窗口变窄时安全减少列数。
- 外观提供透明网格、纯白、浅灰、深灰预览背景，并记住选择。
- 点击素材封面打开预览和详情，在同一窗口修改名称、标签、分类，追加项目归属。音频卡片仍可直接试听。
- 更新按钮常驻，有新版时高亮；新增「作者的话」欢迎致辞。
- 新版／经典版、原有五套配色和动态皮肤继续可用；新增第六套可选配色「清爽蓝白」，采用白底、浅灰胶囊分类与蓝色选中态。AN插件保持已验证的0.3.11。

新增配色不会自动替换当前主题；选择「外观设置 → 清爽蓝白」后立即应用并记住，重启后恢复，布局和预览背景保持原设置。如需纯白素材底，请在「素材预览背景」中另选「纯白」，切换配色不会改变素材预览文件。

分类仅写本地元数据，不移动外部原文件；同一素材加入项目不会复制文件。旧音频和特效即便放在其他分类，也能从对应顶层查看。原有其他分类可从「分类」管理打开。

本地测试使用完整运行目录和原桌面快捷方式。旧目录和快捷方式备份保留，安装包、便携包、提交、推送及公开发布继续暂缓。
