# 0.3.14 本地测试版

2026-11-15。只更新本地测试程序，安装包和公开发布等待测试。

- 使用用户提供的AN标志替换界面、程序和桌面图标。
- 默认顶层：人物、背景、表情、道具、特效、动物异兽、音效、BGM；已有分类保留，可新增项目顶层。
- 一个「导入素材」入口选择普通、特效、音频或图片。可直接拖入窗口，检测后配置分类、类型和预览分辨率，确认后才导入。失败文件保留供重试。
- 复制素材时选择沿用分类、未分类或指定兼容分类，再确认复制。副本自动显示并选中。
- 分类选择按顶层逐级打开，搜索保留路径，添加按钮紧邻分类。
- 详情在预览窗默认折叠，点击展开并记住选择；点击左上角素材名可改名。
- 浏览菜单提供固定分页和滚动浏览，支持自动、24、48、60及1–1000自定义数量。固定分页受当前窗口容量限制以保持无需滚动，自动数量填满完整行；窄窗安全缩列。播放器出现时不遮挡分页。
- 工具菜单整合外观、连接、更新与「投喂作者」，投喂内容暂留空位。六套配色、预览背景、新版／经典版继续可选。

原始素材不改动，分类仍是本地元数据。AN插件保持0.3.11，本轮无新增真实Animate宿主验证。旧程序目录和快捷方式保留回退，不提交／推送／发布。
