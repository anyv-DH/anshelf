# 0.3.15 本地测试版

2026-11-15。只更新完整本地测试程序，安装包和公开发布等待用户测试。

- 新AN标志旁完整显示「安安素材管理器」，经典侧栏也保留完整名称。
- 新版将「导入素材」及「工具」收进顶部分类同一行右侧，减少一行占用；小窗口分类可横向滑动，操作入口保持可见。经典布局继续可切换。
- 预览弹窗底部的拖出、复制、文件位置及AN操作靠右排列，小窗口支持换行。
- 滚动浏览也按每页数量分页，只在当前页内滚动，到底不追加、不自动翻页。通过上下页切换，每页支持自动、24、48、60及1–1000自定义数量；末页只显示实际剩余素材。固定适屏和偏好记忆继续保留。

原始素材不改动，分类仍是本地元数据。AN插件保持0.3.11，本轮无新增真实Animate宿主验证。旧程序目录和快捷方式保留回退，不提交／推送／发布。
