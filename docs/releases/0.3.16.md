# 0.3.16 本地测试说明

本版用于本地测试，暂不生成安装包或便携包，暂不提交、推送或发布。

- 图片卡、预览和组合成员支持「导入 AN」以及原生文件拖出。导入绑定当前 AN 文档和五秒有效期，需要0.3.16接收面板；WebP/GIF转为静态PNG缓存传送，外部原图不变。
- 场景图片可归成一张组合卡，打开后并排显示，每张仍可单独预览、导入及拖出。提供改名、增减、封面、解散、撤销和重启恢复，不使用视角切换器。
- 图片导入勾选「一个文件夹作为一个分组」时，按直接存放图片的小文件夹分别建组。父目录直接图片单独成组，同名不同路径独立；重导入不建重复组，同目录新增图片追加，已有其他组归属保持。默认关闭；单组超过200张会保留导入图片并明确提示未分组。
- 投喂作者窗口使用两张官方原码的本地裁图，只显示清晰白底二维码，无蓝绿外框、用户名或支付方式名称。保留原码像素和静区，两码已离线解码核对。文案统一用「您」，明确开源免费和自愿赠与，可主动前往项目点Star。
- 修复删除图片、重新导入再撤销时的组成员／封面身份映射；统一组合卡鼠标、键盘和Shift范围选择，批量操作仅针对当前匹配成员。

测试重点：重新打开 AN 扩展面板，确认连接中的插件为0.3.16，再测试图片导入与跨窗口拖拽。管理器不会自动保存、关闭或重启 AN。自动化流程不替代真实 Animate 验证，宿主结果待用户实测。
