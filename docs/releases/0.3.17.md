# 0.3.17 本地测试说明

本版更新桌面测试程序，暂不生成安装包或便携包，暂不提交、推送或公开发布。AN 接收面板继续使用0.3.16。

- 修复普通自建顶层文件夹不出现在顶部分类栏的问题。新建后立即选中；较多分类时横向露出当前项，子分类仍留在下一层。
- 去掉「分类」旁的「…」按钮。「更换皮肤」整合进右侧「工具」。
- 启动发现新版会弹窗提示，可设置1–365天内不再弹出，默认7天。设置跨重启记忆，也可随时手动检查；当前已有窗口或操作时延后提醒。
- 弹窗优先提供「一键更新」：您确认后自动下载并校验，完成后正常退出管理器、启动新版安装向导或程序，仍可取消或选择「仅下载」。AN 插件保留「一键安装／更新」，无需去网页另外寻找。未确认时不会开始下载或启动安装。
- 修复特效／音效汇总页里未归类素材无法移除的问题。明确区分从分类移除与从素材库移除，保留确认及撤销，导入的原文件不删除。
- 重新生成预览时，若只是库内副本缺失，可从已登记且内容校验一致的原文件恢复副本，再生成预览；原文件不变。原文件缺失或内容变化时会明确提示。

建议测试：创建一个普通顶层文件夹；在特效页选择一份预览失败素材，打开详情点击「重新生成预览」；分别检查移除与撤销。更新弹窗可在「工具 → 检查更新」设置暂停天数。真实 AN 导入兼容性沿用独立宿主测试边界。
