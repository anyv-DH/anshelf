# 0.3.18 新手引导测试说明

新增直接在页面上操作的新手引导：高亮真实按钮，旁边显示分步说明。六步包括欢迎、导入素材、分类与项目、预览与整理、放进 AN、按习惯浏览。

首次打开自动显示，空素材库也可以完整查看。可以按顺序翻页或点击步骤编号直达，也可随时跳过；完成和跳过都会记住，之后从「工具 → 新手引导」重新打开。

教程介绍四类素材导入、文件拖入、小文件夹分组、项目分类、预览详情、AN 插件安装与连接，以及固定／滚动分页和配色。只看教程不会修改素材；最后可主动选择「去导入素材」或「连接 AN」进入现有功能。

本版仅更新本地桌面测试程序，AN 插件保持0.3.16。安装包、便携包与公开发布继续等待您测试。
