# 安安素材管理器 0.3.20

本版汇总0.3.11至0.3.20的累计更新，面向Windows x64。主程序与随附AN插件均为0.3.20。

## 更大的素材工作区

- 新版采用顶部横向分类和紧凑工具栏，素材获得更宽的预览空间；可随时切回经典布局，保留分类、搜索、选择和分页。
- 外观提供紫夜、暖米、雾白、石墨、青灰、清爽蓝白六套配色，另可选择网格、纯白、浅灰、深灰预览背景。配色与布局独立记忆，不改素材图片。
- 支持自动或每行4–8个卡片，窄窗安全缩列。固定分页和滚动浏览均按当前页显示，支持自动、24、48、60及1–1000自定义每页数量；到底不会自动翻页或继续追加素材。
- 名称、标签和分类集中在预览窗口，详情可折叠；修复从场景组合打开单图时预览变窄或消失的问题。

## 图片与场景组合

- 统一「导入素材」入口支持普通FLA、特效、音频和图片，也可拖入文件后配置类型、分类和预览设置。
- 图片可单独预览、拖出或导入AN。PNG/JPG/JPEG直接传送；WebP/GIF准备静态PNG供AN导入，原图不变。导入绑定当前文档，需要已连接的新版面板。
- 同场景图片可归成一张组合卡，打开后并排查看，每张仍可单独操作；支持改名、增减成员、封面、解散和撤销。
- 导入图片时可勾选「一个文件夹作为一个分组」，按直接存放图片的文件夹分别成组；不同路径的同名文件夹保持独立，重复导入不重复建组。单组最多200张，超出时图片保留并提示整理。

## 预览与分类更好整理

- 已入库的普通／特效FLA可更换PNG、JPG、JPEG、WebP或GIF预览，也可离线重新生成。旧预览保留48小时，支持逐次撤回且重启后仍可用；撤回只恢复图片，不回退后续分类和名称。
- 普通／特效分别记住预览分辨率和同名图复用习惯，包括2048（2K）。导入框创建文件夹后立即选中新分类，保留本次预览设置。
- 顶部「更多分类」支持搜索并直接打开分类、取消或恢复常驻、置前及调整顺序。隐藏只改变本机显示，不删除分类或素材；当前隐藏分类临时显示，切走后收起。
- 新库提供人物、背景、表情、道具、特效、动物异兽、音效、BGM分类；保留已有分类和归属，可用项目文件夹汇集跨类型素材。分类仍是元数据，不移动原件。
- 修复汇总页未归类素材的移除入口。缺失库内副本时，主动重试可从已登记且内容校验一致的原件恢复；不同内容不会被自动覆盖。

## 页面引导与更新提醒

- 首次使用提供六步页面引导，高亮实际控件，空库也可查看；可跳过、关闭或从「工具 → 新手引导」重看。完成与跳过状态保存在本机，查看引导不会改动素材。
- 启动发现新版时最多提醒一次，已有弹窗、正在操作或窗口隐藏时延后。可暂停1–365天（默认7天），也可关闭启动检查或随时手动检查。
- 「一键更新」在明确确认后下载、核对大小与SHA256，再正常退出管理器并启动安装向导或新版程序；可取消、重试或选择「仅下载」。启动检查本身不下载安装器，不上传素材或路径，退出后无常驻更新进程。

## AN插件与保存修复

「加入素材库」的设置使用独立窗口，原小面板尺寸与停靠位置保持。可选择普通／特效、兼容分类、默认至2K预览及同名图复用；确认绑定原文档，切换文档会停止操作。

本版修复已保存且没有新修改的FLA被误判为取消、未提交入库的问题：确认文档已有FLA且没有修改时直接继续，其余情况仍走原生保存。取消或保存失败仍停止，不会把所有失败当成成功。

真实Animate2023独立文档已复验无修改和有修改FLA的原生保存入口，原文档恢复且未改动。该结果不代表完整设置窗到真实用户库、未命名保存取消、图片导入或任务栏拖拽的完整宿主兼容性已验收；Animate2024也仍需独立实测。复杂声音、摄像机、骨骼、脚本、字体等效果请先用作品副本验证，自动预览用于选材参考。

## 怎样升级

1. 安装版和免安装版二选一。退出旧管理器后安装或运行0.3.20，继续沿用 `%APPDATA%\AnShelf` 的素材库和分类，无需重新导入。
2. 在「工具 → 检查更新」或「连接Adobe Animate」中安装／更新随附0.3.20插件，再关闭并重新打开AN面板。插件随软件附带；独立插件包供手动安装或留存。
3. 安装版按向导完成安装；免安装版建议保存在固定文件夹，再更新自己的快捷方式。源代码压缩包用于开发，不是安装程序。

软件不会自动保存、关闭或重启AN。外部最初导入文件保持不变；在AN中打开并保存库内管理FLA，会更新这份库内素材。
