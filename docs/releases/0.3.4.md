# 安安素材管理器 0.3.4

这次更新解决打开素材时名称难认、同一人物只能放一个分类的问题，并补上导入时自动启动 AN 的处理。

## 打开素材，继续用它的名字

点击卡片「用 AN 打开」，工作副本沿用素材名称，例如 `都市人物_女主角.fla`。每次打开使用独立目录，同名素材和重复打开互不覆盖；素材库原件不被编辑或保存操作修改。

## 同一个人物，放进多部剧

1. 选中一份或多份素材。
2. 点击选择栏的「加入其他分类」。
3. 选择目标文件夹，原分类保留。

多个文件夹共享一份素材和预览，搜索结果不会因多分类产生重复卡片。收藏也沿用这些分类路径。需要整体迁移时，使用原来的「选择分类」替换归属；打开详情，点击某个分类旁的 ×，只取消该分类，操作支持撤销。

## 导入时尝试自动启动 AN

需要自动生成预览的 FLA 导入后，如果 AN 没有运行，管理器会查找并启动已安装的 Adobe Animate；已有 AN 进程时不会重复启动。使用已有同名预览和导入音频不额外启动 AN。

进程检查在后台执行，不挡住导入、预览或下一次点击。找不到 AN 时会提示，已导入的素材仍会保留，离线预览继续处理。自动预览用于选材参考，复杂 FLA 可能需要重试或提供同名预览。

## 下载和更新

- 推荐安装版：`AnAn-AssetManager-Setup-0.3.4.exe`。
- 免安装便携版：`AnAn-AssetManager-Portable-0.3.4.exe`。
- AN 接收面板：`AnAn-AssetManager-AnimatePlugin.zip`，解压后运行 `install.ps1`，重启 AN，在「窗口 → 扩展 → 安安素材管理器」打开面板。
- 已安装并正常使用面板的用户，本次无需重复安装面板。

退出旧管理器后启动新版，继续读取同一台电脑 `%APPDATA%\AnShelf` 中的素材库，不需要重新导入。完整操作图解见 [使用说明](../../README.md)。

248 项自动回归通过；真实打包程序验证多分类共享、取消与撤销、保留名称的工作副本、重启保存和三种导入分类入口。自动启动的无进程分支由受控测试覆盖，本机真实安装路径识别与已运行状态检查通过；没有关闭用户正在工作的 AN 来测试冷启动。
