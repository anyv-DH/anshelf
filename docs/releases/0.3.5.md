# 安安素材管理器 0.3.5

这次更新解决小文件导入结束后又弹出 AN，以及部分旋转特效生成动图时跑偏的问题。

## 导入后，不再多弹一个 AN

普通素材和特效都使用本机后台预览，不需要提前打开 AN。导入、失败后重试、已有同名预览和音频都不会额外启动 AN；小文件快速导入后，也不会留下一个延迟启动任务。预览继续逐个生成，导入完成即可浏览、分类和继续选材。

「用 AN 打开」继续打开保留素材名称的独立工作副本；拖拽、磁力粘贴和按钮粘贴继续需要打开 AN 与接收面板。

## 旋转特效，围绕正确的中心转

修复经典旋转补间忽略元件变换中心的问题：原本在中间旋转的特效，不再因为注册原点不同而绕圈漂移。正常的位移和缩放仍保留。

已生成的旧动图不会批量重算。找到对应特效，打开详情，点击「重新生成预览」即可更新；原始 FLA 不会被修改。复杂脚本、字体、滤镜和其他动画类型仍可能与 AN 有差异，自动预览用于选材参考。

## 下载与更新

- 安装版：`AnAn-AssetManager-Setup-0.3.5.exe`。
- 免安装版：`AnAn-AssetManager-Portable-0.3.5.exe`。
- 舞台粘贴面板：`AnAn-AssetManager-AnimatePlugin.zip`。本次面板运行内容未变，已正常使用的用户无需重装。

退出旧管理器后启动新版，继续读取本机 `%APPDATA%\AnShelf` 素材库，不必重新导入。详细图解见 [使用说明](../../README.md)。
