# 安安素材管理器 0.3.6

修复重复打开便携版后，新导入素材显示“暂时无法预览 / 预览失败”的问题。

## 为什么主界面正常，却生成不了预览？

旧便携版的多次启动共用同一个临时解压目录。再次双击程序时，即使最后只是唤起原窗口，启动器也可能清理原窗口仍要使用的运行文件，导致后台预览窗口无法启动。这时素材已成功入库，预览却失败。

新版为每次启动分配独立的临时运行目录，避免互相清理。导入和预览继续完全在本机处理，不需要启动 AN，也不修改原始 FLA。

## 如何更新与恢复失败预览

1. 退出旧管理器，打开 0.3.6。
2. 原有素材库和分类继续读取，无需重新导入。
3. 对已显示“预览失败”的素材，打开详情，点击“重新生成预览”。

本次只修复程序运行文件被清理的问题，不改变 FLA 渲染兼容范围；复杂脚本、字体和滤镜仍可能与 AN 的显示不同。

- 免安装版：`AnAn-AssetManager-Portable-0.3.6.exe`。
- 舞台粘贴面板：`AnAn-AssetManager-AnimatePlugin.zip`。插件没有改动，正常使用的用户无需重装。
