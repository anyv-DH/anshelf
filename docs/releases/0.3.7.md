# 安安素材管理器 0.3.7

## 本次修复

之前点击「用 AN 打开」时，管理器会为每次打开创建一份 FLA 工作副本。AN 保存的是副本，因此素材库原记录和自动预览仍指向导入时的旧内容。

0.3.7 改为直接打开素材库里的唯一 FLA。首次打开只在素材库内原位重命名，不复制文件内容；之后保存、再次打开或粘贴时，管理器会检查文件哈希。发现修改后自动更新记录并重新生成预览。最初导入位置的源文件保持不变。

「粘贴到舞台」也不再把整份 FLA 复制到 `bridge/temp`，或一次性加载到一个大内存缓冲区。新版 AN 面板使用 1 MiB 缓冲区分块校验，再从管理器的唯一素材文件直接读取。素材已经在 AN 打开时，面板会提示先关闭素材文档，避免影响当前编辑内容。粘贴完成后素材源文档不保存并关闭，目标作品保持打开。

## 更新 Animate 面板

0.3.7 的面板通信协议为版本 2。更新桌面软件后，还要从本次发布页下载新版 `AnAn-AssetManager-AnimatePlugin.zip`，解压后运行 `install.ps1`，然后重启 AN。旧版面板会被桌面端识别并提示更新。

## 数据与限制

- 现有素材库、分类、预览和原始文件路径继续使用，不需要重新导入。
- 素材库中的管理文件会被 AN 直接编辑；保存后它就是新的素材版本。
- 导入目录中的外部原文件不会随 AN 保存而改变。
- 0.3.7 不会自动删除旧版本已经创建的 `opened` 工作文件，避免误删其中可能保存的内容。
- 用 AN 打开后若还想粘贴同一素材，先保存并关闭该素材文档，再执行粘贴。

## 验证

本版通过全量自动测试、素材保存后重开/重启回归、直接读取桥接契约、无临时 FLA 断言和打包一致性检查。新桥接流程需要在本机 Animate 中用更新后的面板再手工验收；自动化契约测试不代表已完成该实机检查。
