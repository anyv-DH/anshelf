## 复制一份，继续做新素材

鼠标移到素材卡片上，点击名称右侧的双页图标「复制一份新文件」。放大预览底部和素材详情中也有这个按钮。

确认窗口会显示保存文件夹；点击「确认复制」后，管理器把素材库内最新保存的文件复制到原始文件所在的文件夹，然后在 Windows 资源管理器中选中新文件。新文件命名为「素材名 - 副本.fla」，重名时从「副本 (2)」递增。音频保持原来的扩展名。原始文件夹已失效时，会请你选择保存位置。

只有主动点击才创建这份文件；不会覆盖原文件、移动原素材、自动将副本导入素材库或复制预览图。源素材在 AN 中有尚未保存的修改时，请先保存，再复制。

## 从 AN 把当前文档加入素材库

1. 更新本版 AN 面板，并打开安安素材管理器。
2. 在 AN 中打开要收藏的 FLA，点击面板新增的「加入素材库」按钮（托盘加号图标）。
3. 面板先询问是否保存并加入素材库；确认后才保存当前文档；尚未保存的文档会出现 AN 自带的保存窗口。取消保存就取消加入。
4. 新文件按普通素材导入并自动排队生成预览，可回管理器选择分类、收藏或标签。已存在的相同内容会去重；如果当前打开的就是库内素材，则更新原记录和预览，保留原分类及素材类型。

管理器需要保持运行。没有打开管理器时会提示等待，超时后可打开管理器再点击。支持已保存的本地 FLA，XFL 请先另存为 FLA。面板不关闭当前文档，也不创建额外工作副本。导入一个新的外部文档仍按原有机制在库内保存一份受管理文件，保证库可以独立使用。

AN 面板保留紧凑布局，两个图标并排，默认内容区约 88×48；悬停可读完整说明。原有按钮粘贴、拖拽粘贴与当前帧规则保留。

## 更新方法

1. 保存正在制作的 AN 作品，然后退出旧版管理器。
2. 选择上表的安装版或免安装版更新到 0.3.8；同一电脑、同一系统账户下，原素材库与分类继续沿用，不需要重新导入。
3. 另外下载本版 AN 插件，完整解压后，在原插件文件夹中运行 `install.ps1`，不要只取出脚本。
4. 重启 AN，在「窗口 → 扩展 → 安安素材管理器」打开新版面板；保持管理器同时运行。

仅更新主程序不会自动更新 AN 面板，也不会出现「加入素材库」新按钮。日后找新版本，可从 [最新版下载页](https://github.com/anyv-DH/anshelf/releases/latest) 查看对应更新说明。

## 启动时提醒有新版

0.3.8 起，打开管理器约 3 秒后，自动进行一次轻量的 GitHub 版本检查；发现更高版本时提示前往下载页。界面也提供「检查更新」和关闭自动检查的选项。

没有网络也能正常导入、预览、分类和使用素材。检查只读取版本信息，不自动下载或安装软件；退出管理器后不保留常驻更新进程。

旧版 0.3.7 及更早版本没有这项提醒，需要先手动下载安装或打开 0.3.8，之后才能使用启动检查功能。

## 图片、GIF、视频都可以做底图皮肤

点击侧栏「更换皮肤」，选择本机 PNG、JPG、JPEG、WebP、GIF 图片或 MP4、WebM 视频，再调整背景遮罩深浅。图片上限 40 MB、视频上限 300 MB；素材卡片保持不透明，避免影响选材。

视频静音循环播放，支持暂停；GIF 暂停时暂时隐藏。窗口切到后台或最小化时暂停动态底图，回到管理器再按原设置恢复。系统「减少动态效果」开启时默认暂停，可以手动开启。

皮肤只引用原媒体文件，不会复制大图或视频。原文件移走、删除或无法解码时恢复默认显示，重新选择即可；「恢复默认」也不会删除你的原媒体文件。

本版不迁移或删除已有素材，不把任何个人素材上传到网络。
