## 多个分类，共享一份素材也能放心编辑

- 修复「加入其他分类」后，在另一个分类打开素材提示文件不存在的问题。分类共享同一个素材记录和管理文件。
- 修复旧版撤销记录把素材路径、已保存内容的哈希或新预览退回旧值的问题；撤销分类、名称等操作仅回退对应元数据。
- 修复移除后重新导入，再撤销时产生两个记录争用同一个可重命名文件的问题；安全合并分类和收藏等归属，保留当前已保存文件。
- 修复 Windows 路径斜杠或大小写不同，却把同一个 FLA 误认成两份并清理掉的情况。同一物理文件只规范路径记录，不重命名、不删除。
- 旧记录指向丢失路径时，只在该素材自己的管理目录内查找；发现不同版本会提示人工确认，不自动挑选覆盖。不会为修复路径复制整份 FLA。

管理器不会替 AN 保存尚未保存的编辑；需要保留修改时，请先在 AN 中保存。

## 「移出这个分类」和「从整个库移除」分开了

在真实分类内选中素材，点击「从当前分类移除」，只取消当前分类及其子分类中的归属，其他分类、素材库记录和文件都保留。没有其他归属的素材会出现在「未分类」。

需要从所有分类、收藏和点赞中移除同一条素材记录时，使用独立的「从素材库移除」。全部素材、收藏、点赞等虚拟视图中的移除也会清楚说明全库范围。确认窗口会显示影响范围，支持取消和撤销；导入目录中的外部原文件不会被删除。

删除分类、移除素材、复制新文件均使用与软件配色一致的确认窗口。复制前仍会列出保存文件夹，取消不写文件；只有主动「复制一份」才会创建新文件。

## AN 插件在软件里直接安装／更新

1. 打开管理器左下角「检查更新」，或打开「连接 Adobe Animate」。
2. 在「AN 插件」区域查看软件附带版本和已安装版本。
3. 点击「安装／更新 AN 插件」，阅读确认后安装。
4. 关闭再打开 AN 中的「安安素材管理器」面板；必要时保存作品后重启 AN。

插件在本机从随软件附带的签名目录安装，校验失败不会覆盖正常安装，旧版保留可恢复备份。签名为项目本地自签，不代表 Adobe 审核。管理器不会自动保存、关闭或重启 AN，也不会替您关闭正在制作的作品。

### 两个按钮，竖着放更省空间

面板默认约 48×88，最低 40×80，上面是「粘贴到舞台」，下面的加号是「加入素材库」。窄栏仅显示图标，悬停有说明，拉宽后显示文字；外层标题和最终停靠尺寸仍由 AN 控制。

<img src="https://raw.githubusercontent.com/anyv-DH/anshelf/v0.3.9/docs/images/panel-vertical-039.png" alt="AN 竖排面板：上面粘贴，下面加入素材库" width="48">

「加入素材库」先显示紫色确认窗口。窄浮动面板会尝试临时放大，操作后恢复尺寸；停靠栏不能放大时使用 AN 原生确认。取消不保存、不入库，确认后才保存；未命名文件继续使用 AN 自带保存窗口。确认期间切换了文档会停止，避免保存错文件。

![加入素材库的紫色确认窗口](https://raw.githubusercontent.com/anyv-DH/anshelf/v0.3.9/docs/images/panel-confirmation-039.png)

库内文档更新原记录与预览，不创建额外工作副本。新外部 FLA 按正常导入机制保存一份库内文件；相同内容去重并保留已有分类、类型和预览设置。管理器需保持运行。

## 主程序：您点下载，校验完成后再启动更新

启动检查仍只获取一次公开版本信息，不会自动下载或安装。发现新版后，可在更新窗口手动下载；下载显示进度，按当前使用方式选择安装版或免安装版，并核对官方附件大小和 SHA256。取消或下载失败不会启动更新。

下载完成后，可先「打开文件位置」，或主动点击启动更新：

- **安装版**：点击「退出并更新」并确认，退出当前管理器后进入新版安装向导，按向导安装；不需要先删除素材库。
- **免安装版**：新版保存在 `%APPDATA%\AnShelfUpdates` 的持久目录，点击「退出并打开新版」并确认，退出当前管理器后打开新版。不会覆盖原来的 EXE 或快捷方式；以后请使用新版文件，或为它更新快捷方式。

素材库仍沿用 `%APPDATA%\AnShelf`。0.3.8 只有版本提醒，需要先从本页手动更新到 0.3.9 才有软件下载与插件安装入口；0.3.7 及更早版本也需手动升级。无法联网时，本地导入、搜索和分类仍可使用。
